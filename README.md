# CS-330-Module-Eight# 


For my CS 330 final project, I created an interactive 3D desktop workspace using C++ and OpenGL. The scene was based on a reference image and included a computer monitor, keyboard, mouse, coffee mug, stacked books, pencil holder with pencils, and a desktop surface. I built the objects using basic 3D shapes, then added textures, lighting, and camera controls to make the environment more complete and interactive.

## How do I approach designing software?

This project helped me improve the way I break a larger idea into smaller pieces before I start coding. Instead of trying to build the entire desktop scene at once, I looked at each object and determined which basic shapes could represent it. For example, the monitor was created from multiple simple shapes for the screen, frame, stand, and base, while other objects such as the keyboard could be simplified into a box.

My design process was very iterative. I started with basic geometry and focused first on getting the proportions and placement correct. After that, I added camera controls, textures, and lighting in separate stages. This made it much easier to identify problems because I could test one part of the scene at a time.

I can apply this same approach to future software projects by separating large requirements into smaller components, building and testing them individually, and then combining them into a complete system. Planning for reusable classes and functions also makes later changes easier.

## How do I approach developing programs?

One of the biggest development strategies I used during this project was incremental development. Each milestone added another layer to the same application. I first worked with basic OpenGL shapes, then added camera navigation, texture mapping, lighting, and finally additional objects and polish.

Iteration was a major part of the process. Many parts of the scene did not look correct on the first attempt. I had to adjust object positions, scaling, texture coordinates, lighting intensity, camera placement, and material properties several times. Seeing the result visually after each change helped me understand how the code affected the final scene.

My approach to programming also became more organized as the course progressed. Earlier work relied more heavily on individual rendering functions. As the project developed, I moved toward separating responsibilities into reusable functions and classes. For example, the monitor could be treated as its own object instead of having all of its rendering logic mixed into the rest of the scene. This made the project easier to understand and maintain.

## How can computer science help me in reaching my goals?

Computational graphics gave me experience with concepts that I had not worked with much before, including 3D coordinate systems, transformations, vectors, camera movement, texture mapping, shaders, and lighting calculations. These concepts strengthened my understanding of how mathematics and programming can work together to create something visual and interactive.

From an educational perspective, these skills give me a stronger foundation for future work involving game development, simulations, virtual environments, graphics programming, and other areas of computer science that use visualizations.

Professionally, this course also strengthened skills that apply beyond graphics. Building the scene required debugging, modular programming, testing changes incrementally, managing multiple project files, and turning a visual requirement into working software. Those skills can transfer to many software engineering roles, even when the application does not involve 3D graphics.

If I continued developing this project, I would like to explore more advanced techniques such as shadows, collision detection, animation, physics, normal mapping, and more realistic reflections. I would also like to learn how modern game engines apply many of the same concepts from OpenGL while managing much larger and more complex environments.
